    • track(config: TrackConfig): Promise<TrackResult>

      Resolves to a terminal outcome: confirmed, landed-but-failed, or expired.

      Termination is the canonical Solana rule: the loop is bounded solely by lastValidBlockHeight (block height passing the deadline), never an arbitrary poll cap that could mask the real bound. The WebSocket fast-path, when configured, can only RESOLVE EARLIER (confirmed/failed) — it can never extend the loop or override expiry.
